# Security

Please report a security problem in the Astraeus plugin privately, by email to
**support@cosmicvaults.com**, and not as a public GitHub issue.

Say which plugin version you are on (N.I.N.A. shows it under **Plugins > Installed**), what you
found and how to reproduce it. We will reply, keep you informed while it is fixed, and credit you
in the changelog if you would like.

The plugin talks only to the Astraeus server at astraeus.cosmicvaults.com, and to devices and
cameras you configure on your own network. Problems with the Astraeus website or server can be
reported to the same address.
